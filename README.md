# Azure Cove Resort Demo Website

A responsive fictional resort website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` - page structure and content
- `style.css` - responsive styling
- `script.js` - mobile navigation, date validation and inquiry form behavior

## Run locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and the remote Unsplash photos.

## Deploy with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and this README into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Demo notes / before using for a real resort
- Azure Cove Resort is a fictional brand and all room names, rates, contact details and location copy are sample content.
- Replace the sample details, images and rates with authorized business information.
- The availability form validates dates and guides visitors to the inquiry form. It does **not** check live room inventory or create reservations.
- The contact form prepares an email draft using the visitor's email application. It does not send or store inquiries. Replace `hello@azurecove.example` with the resort's real email.
- This is a static front-end demo. Live booking, payments, customer records, admin tools and reservation management require a secure backend and database.
